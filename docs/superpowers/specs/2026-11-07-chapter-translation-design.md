# Перевод глав на лету через DeepL

Дата: 2026-11-07. Статус: утверждён владельцем.

## Зачем

Владелец читал новеллу Doomsday Jigsaw Puzzle на русском, и перевод оборвался.
Хочется продолжать чтение без ожидания переводчиков, не теряя читаемость: имена
и термины должны совпадать с уже прочитанным русским переводом.

Проверка на реальном телефоне показала:

- На Webnovel полный текст есть только у глав 1–22. Глава 23 и дальше (проверено
  до 55-й) отдают обрезок примерно на 1000 символов.
- На Quanben есть китайский оригинал: 末日拼图游戏, автор 更从心, 640 глав,
  завершён. Плагин `quanben` уже есть в каталоге LNReader. Проверены главы 1, 23
  и 500, текст полный.
- DeepL без словаря портит имена: 白雾 превращается в «Бэй Ву» вместо «Бай У».
- Китайская глава занимает 2200–4700 символов (выборка из трёх глав).
- На телефоне лежит русская версия: 901 глава в `Novels/RLIB/28`.

## Цели

- Переводить отдельную главу по запросу, с любого языка на любой, через DeepL.
- Работать с любым плагином-источником. Перевод не привязан к Quanben.
- Переводить лениво: только открытую главу или главу, для которой нажата кнопка.
- Быстро переключаться между оригиналом и переводом в читалке.
- Применять словарь DeepL, чтобы имена и термины были единообразны.
- Загружать готовый файл словаря для книги.

## Не цели

- Автоматический перевод всей книги.
- Подстановка терминов на стороне приложения. Словарь применяет только DeepL.
- Другие сервисы перевода в этой версии.
- Показ оригинала и перевода рядом, абзац к абзацу.
- Перевод картинок.
- Автоматическая сборка словаря внутри приложения.

## Что точно нельзя допустить

- Тихая трата лимита: приложение не переводит ничего, о чём пользователь не просил.
  Открытая глава при включённом переводе считается просьбой, следующая глава —
  нет (см. решение 4).
- Обрезанная, битая или пустая глава под видом перевода.
- Потеря оригинала: перевод никогда не заменяет исходный текст главы.
- Утечка ключа DeepL через резервные копии.
- Изменение поведения для тех, кто перевод не включал.

## Решения владельца

1. Перевод только поглавный и ленивый. Вся книга не переводится.
2. Рядом с кнопкой загрузки в списке глав есть кнопка перевода, она переводит
   главу заранее.
3. В читалке переключатель в верхней панели (вариант A в макете): нажатие
   переключает оригинал и перевод, долгое нажатие открывает выбор языков.
4. Языки можно выбирать, в настройках книги задаются исходный и целевой языки.
5. Словарь применяет сам DeepL. Подстановки в приложении нет.
6. Для книги можно загрузить файл словаря.
7. Автоматической сборки словаря в приложении в этой версии нет. Словарь этой книги
   собирается из существующего перевода на компьютере и загружается файлом.
8. Источник текста не важен. Для этой книги используем китайский оригинал.

## Как это работает для пользователя

Настройка один раз: в общих настройках вводится ключ DeepL API. Приложение
проверяет ключ и сразу сообщает, если он неверный.

Настройка книги: в меню книги задаются исходный и целевой языки и загружается
файл словаря. Приложение создаёт словарь в DeepL и показывает число записей.

Список глав: у каждой главы рядом с загрузкой есть кнопка 文 с тремя состояниями:
не переведена, переводится, перевод сохранён. Нажатие на непереведённую главу
запускает перевод. Для сохранённой открывается меню с пунктом удаления перевода.

Читалка: кнопка 文 в верхней панели переключает текст. Если перевода ещё нет,
глава переводится и сохраняется, а пока идёт запрос, виден индикатор. Выбранный
режим запоминается для книги, поэтому следующая глава открывается в том же режиме.

Ошибка: при неверном ключе, исчерпанном лимите или обрыве сети показывается
оригинал и понятное сообщение. Ошибка не сохраняется как перевод.

## Устройство

Перевод встраивается в приложение, а не в плагин-источник: плагины LNReader только
получают главы с сайтов. Точка подключения — загрузка текста главы в
`src/screens/reader/hooks/useChapter.ts` (`loadChapterText`, `loadChapterHtml`).

Известные ограничения кода, которые надо учесть:

- `chapterTextCache` ключуется по `chap.id`. Оригинал и перевод не должны
  затирать друг друга в этом кеше.
- `deleteChapter` удаляет всю папку главы (`src/database/queries/ChapterQueries.ts`).
  Поэтому переводы лежат не в ней, а в отдельной папке книги, чтобы удаление
  загрузки не стирало оплаченный перевод. Папка книги удаляется вместе с книгой.
- `backupMMKVData` в `src/services/backup/utils.ts` сохраняет значения MMKV в
  резервную копию. Ключ DeepL надо исключить из неё. Отдельного защищённого
  хранилища в проекте нет.
- Новые строки интерфейса добавляются только в `src/i18n/languages/en/strings.json`,
  затем запускается `pnpm run generate:string-types`.
- Изменения схемы БД идут через `pnpm run generate:db-migration`.

### DeepL

- Перевод: `POST /v2/translate`, HTML-разметка главы сохраняется.
- Словари: API `/v3/glossaries`. Словарь действует на конкретную языковую пару.
- Ключ с окончанием `:fx` работает через `https://api-free.deepl.com` (проверено),
  остальные ключи — через `https://api.deepl.com`.
- Глава отправляется обычным текстовым запросом, а не файлом: файл считается
  минимум за 50 000 символов.

### Формат словаря

Файл TSV в UTF-8, две колонки: исходный термин и перевод. Этот формат принимает
DeepL. Дублирующиеся исходные термины отклоняются с понятным сообщением.

## Словарь этой книги

Решение владельца: автоматическая сборка словаря в приложении отменена на эту версию.
Приложение только загружает готовый файл TSV. Словарь для этой книги собирается один
раз на компьютере, вне кода приложения, и передаётся владельцу готовым файлом.

Сборка — отдельная задача, не часть кода приложения:

- Источники: китайский текст с Quanben и 901 русская глава с телефона.
- Имена: китайское сочетание записывается по системе Палладия (白雾 → bái wù → Бай У) и
  ищется среди слов с заглавной буквы в русском тексте. Проба на 18 главах дала 45
  кандидатов, среди них около шести ложных, например 研究 → Янь Цзю.
- Термины (高塔 → Башня, 调查军团 → Расследовательский корпус) сопоставляются вручную
  при сборке по параллельным отрывкам.
- Главное правило: лучше пропустить запись, чем добавить ложную. Ложная запись заменит
  обычное слово во всей книге.
- Объём: не больше 1000 записей, это лимит тарифа Developer на языковую пару.

## Решения автора документа

1. Перевод хранится отдельно от загруженной главы, поэтому работает и для
   незагруженных глав.
2. Файл перевода привязан к паре языков. Смена языка не удаляет старый перевод.
3. Смена словаря не переводит уже готовые главы заново. В меню главы есть пункт
   «Перевести заново».
4. Следующая глава заранее не переводится: автоматический перевод тратил бы лимит
   без запроса. Это отменяет прежнее предложение о подготовке следующей главы.
5. Название главы переводится вместе с главой и показывается в читалке. Массовый
   перевод названий в список глав в эту версию не входит.
6. Ключ нужен только для новых переводов. Без ключа кнопки запуска перевода не
   видны, но сохранённые переводы читаются и переключаются как обычно.
7. Озвучивание (TTS) и поиск работают с тем текстом, который сейчас показан.
   Экспорт в EPUB в этой версии использует только оригинал.
8. У книги один словарь на языковую пару. Если словаря для выбранной пары нет,
   глава переводится без него. Если словарь задан, но DeepL его не нашёл, перевод
   останавливается с понятным сообщением: лимит не тратится на неверные имена.
   Вместе с переводом сохраняется, какой словарь применён.
9. Гарантия от битой главы касается ответа DeepL: все части получены, текст не
   пустой. Определять обрезанный источник приложение не пытается, надёжного
   общего признака нет.
10. Автопереход TTS не считается просьбой о переводе. Если следующая глава не
    переведена, а режим перевода включён, озвучивание останавливается с сообщением.
    Сохранённый перевод читается дальше как обычно.
11. Сохранённые переводы в этой версии не переносятся через восстановление из
    резервной копии и миграцию книги. Это принятая потеря: при необходимости глава
    переводится заново. Файлы переводов не должны мешать восстановлению.

## Оставлено исполнителю

- Схема хранения состояния «перевод сохранён» (колонка в БД или проверка файлов)
  с учётом скорости длинного списка глав.
- Разбиение очень длинных глав под лимит запроса DeepL.
- Очередь и параллельность при нескольких нажатиях кнопки перевода.
- Подробности экранов настроек в стиле существующих экранов.

## Проверка

- Тесты на основную логику: выбор оригинала или перевода, сохранение, ошибки,
  разбор словаря, отсутствие ключа в резервной копии.
- Тесты на взаимодействие: кнопка в списке глав и переключатель в читалке.
- `pnpm run check` и соответствующие проекты Jest.
- Ручная проверка на Pixel с книгой из Quanben: глава 1 и глава 23 с настоящим
  ключом, включая написание «Бай У» со словарём.

## Открытые риски

- Страница тарифов DeepL (скриншот владельца, 2026-11-07) указывает для бесплатного
  API Developer: 1 млн символов разово, 1 ключ, 1 словарь, 1000 записей на языковую
  пару. Этого хватает на одну книгу и примерно 200–450 китайских глав.
- Проверено настоящим ключом Developer 2026-11-07: словарь zh→ru создаётся через
  `/v3/glossaries`, применяется в `/v2/translate` вместе с `tag_handling: html`,
  разметка сохраняется, а термины склоняются («в Башню», «Расследовательского
  корпуса»). Проверка шла на трёх коротких абзацах, не на целой главе.
- Для второй книги со словарём или сверх лимита нужен Growth: $26 в месяц при оплате
  за год и $27,50 за 1 млн символов сверх пакета. Страница показывает цены для
  Кыргызстана, но сама оплата не проверялась.
- Словарь этой книги надо уложить в 1000 записей.
- Quanben — неофициальный агрегатор, доступность сайта не гарантирована.
